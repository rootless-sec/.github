### Overview

Rootless Security is an independent systems and offensive security collective founded by [@Mafifrizi](https://github.com/Mafifrizi) and [@TifalAbdusyahid](https://github.com/TifalAbdusyahid). 

We engineer unprivileged tooling, explore hybrid Active Directory identity internals, and build deterministic adversary emulation systems.

- **Rootless by Design**: Zero requirement for `root`, `sudo`, or elevated host privileges.
- **Protocol Ground-Truth**: RFC 4120, RFC 6113 FAST armoring, MS-PAC NDR decoding, and LDAP binary attributes.
- **Operational Discipline**: Deterministic OPSEC guardrails, memory zeroization, and defensive telemetry coupling.
